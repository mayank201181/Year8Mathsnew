# Year 8 Maths Lab — working notes

- Content lives in `lib/topics/<id>/{guide,mcq,practice,practice2}.ts`, drills in `lib/drills/<id>.ts`,
  engagement extras in `lib/extras/<id>.ts`, widgets in `components/widgets/<id>.tsx`, exam papers in
  `lib/exam/*.ts`. Specs: `docs/CONTENT.md`, `docs/AUDIT.md`, `docs/DRILLS.md`, `docs/WIDGETS.md`, `docs/UI.md`.
- `lib/generated/*` and `components/widgets/registry.ts` are generated by `npm run gen` (runs automatically before dev/build).
- Content is server-only (`lib/server/content.ts`); client code fetches questions via `/api/questions`.
- Before committing: `npm test`, `npm run validate`, `npm run lint`, `npm run build`.
- Never change question ids (saved progress and spaced review reference them).
